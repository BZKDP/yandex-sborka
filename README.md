# Яндекс.Маркет FBS — сборка заказов

Набор Python-скриптов для подготовки заказов Яндекс.Маркета по схеме FBS: получение
заказов и отгрузок через Partner API, построение листа подбора с фотографиями товаров
и склейка/печать транспортных этикеток.

## Что делает
- Забирает заказы и отгрузки FBS через Yandex Market Partner API.
- Подтягивает карточки товаров (названия, штрихкоды, фото) и качает фото.
- Строит лист подбора/сборки в HTML и рендерит в PDF (через headless Edge).
- Скачивает этикетки заказов (формат A9, 40×58 мм) и склеивает их одним файлом.
- Умеет работать с остатками: выгрузка, пополнение единичных SKU, снятие скрытия.

## Основные скрипты
- `build_all.py` — заказы «ожидают сборки» по всем кабинетам: фото, этикетки, лист подбора.
- `build_shipment.py` — комплект по одной отгрузке (этикетки + лист + акт), подтверждение отгрузки.
- `build_ship_data.py` / `build_ship_sheet.py` — выгрузка отгрузок и лист сборки по ячейкам склада.
- `build_ordlist_*.py` — лист подбора/сборки по заданному списку заказов.
- `stock_*.py`, `unhide.py`, `verify*.py` — работа с остатками и статусами карточек.
- `classify.py` — разбивка SKU на единичные и комплекты (результат в `classified.json`).

## Настройка
Задайте переменные окружения (см. `.env.example`): `YM_API_KEY`, `YM_OAUTH_TOKEN`,
`YM_CAMPAIGN_ID`, `YM_BUSINESS_ID`. Для резолвинга складских ячеек нужны `WMS_DB_*`.
Зависимости: `pip install requests pypdf PyMuPDF psycopg2-binary`.

## Запуск
`python build_all.py` — собрать лист подбора и этикетки по текущим заказам.
`python build_shipment.py active` — обработать отгрузки «Можно обрабатывать».

## Примечание о комплектах
Комплекты (наборы из нескольких банок) определяются эвристикой по названию в `classify.py`;
спорные позиции проверяются по фото вручную, чтобы не пополнять их остаток как единичные.
